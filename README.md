# My brainf*ck interpreter (no joke)
## About
A very simple interpreter for the language brainfuck which I wrote under 100 lines to prove to myself how simple this works.
I also tested it by running the typical bf Hello world program which actually works. I realized I could actually make a compiler of some sort since the assembly code (NASM) would not look that spectacular but I got other things to do and this is just a small gimmick no actual "serious" project
